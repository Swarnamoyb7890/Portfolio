# 🚀 Modern Web Developer Portfolio

A premium, high-performance personal portfolio built with **React 19**, **TypeScript**, and **Vite**. This project showcases a clean, interactive UI with advanced CSS effects, modular architecture, and a focus on web development expertise.

## ✨ Key Features

-   **💎 Premium Glassmorphism UI**: A modern design language featuring semi-transparent surfaces, advanced blurs, and sophisticated shadows.
-   **🌌 Animated Starry Background**: A custom-built, lightweight CSS particle system and animated gradients that bring the background to life.
-   **📊 Interactive Skill Bars**: Scroll-triggered skill visualizations with proficiency labels and hover-glow effects.
-   **📱 Responsive & Fluid**: Fully optimized for all screen sizes, from mobile to ultra-wide monitors.
-   **🎯 Refined Navigation**: A floating pill-shaped navbar with smart active-state tracking and smooth scroll-padding.
-   **🖼️ Custom Branding**: Integrated personal logo watermark and interactive brand elements.
-   **🛠️ Modular Architecture**: Cleanly separated components and scoped CSS for maximum maintainability.

## 🛠️ Tech Stack

-   **Frontend**: React 19, TypeScript
-   **Build Tool**: Vite
-   **Styling**: Pure CSS (Modern Variables, Flexbox, Grid, Animations)
-   **State Management**: React Hooks (useState, useEffect, useRef)
-   **Performance**: Intersection Observer API for scroll-triggered animations

## 📁 Project Structure

```text
src/
```

## 🚀 Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/Swarnamoyb7890/Portfolio.git
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Start development server**:
    ```bash
    npm run dev
    ```
4.  **Build for production**:
    ```bash
    npm run build
    ```
